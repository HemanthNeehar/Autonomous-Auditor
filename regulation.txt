
REGULATION DOCUMENT: RG-101 (Retail Data Compliance)

SECTION 1: PII (Personally Identifiable Information)
    - Rule 1.1: Customer PII (defined as 'email', 'phone', 'address') must not be stored in a non-anonymized format in the 'orders_db'.
    - Rule 1.2: All PII in 'orders_db' must be explicitly set to "[MASKED]".
    - Rule 1.3: PII fields in 'orders_db' must not contain error codes, 'NULL', or 'N/A'. They must be '[MASKED]'. This is a PII Integrity Failure.

SECTION 2: RTBF (Right to be Forgotten)
    - Rule 2.1: If a customer in 'customer_db' has a status of 'forgotten', that customer's 'customer_id' must not appear in any record in 'orders_db'.
    - Rule 2.2: An audit must confirm zero orders are associated with 'forgotten' customer_ids.

SECTION 3: Data Retention
    - Rule 3.1: Order records older than 3650 days (10 years) must be anonymized.
    - Rule 3.2: The 'customer_id' on these old records must be set to 'ANONYMIZED'.

SECTION 4: Data Governance & Integrity
    - Rule 4.1: Every 'customer_id' in 'orders_db' must correspond to a valid 'customer_id' in 'customer_db'.
    - Rule 4.2: Records in 'orders_db' without a valid parent customer are "Orphaned Records" and are a compliance violation.
